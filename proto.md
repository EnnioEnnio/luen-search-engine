# Protocol Buffers & gRPC Guide

This project uses [gRPC](https://grpc.io/) for communication between the Go backend (client) and the Python embedding service (server).

This document explains **what** these technologies are, **why** we use them, and **how** the files in this project interact.

## 1. The High-Level Concept

We have two separate worlds that need to talk to each other:
*   **Go World**: Our fast, compiled search engine core.
*   **Python World**: Our flexible, AI-powered embedding service using PyTorch.

They cannot "import" each other's code. They need a common language to send messages back and forth over the network. That common language is **Protocol Buffers (Protobuf)**.

## 2. Directory Structure Explained

### `proto/` (The "Contract")
This folder contains the **Interface Definition Language (IDL)** files.
*   **`proto/search.proto`**: This is the single source of truth. It looks like code, but it's actually a schema. It defines:
    *   **Messages**: What data looks like (`SearchRequest` has a string `query`).
    *   **Services**: What functions are available (`rpc Search`).
    *   It is language-neutral. It doesn't know about Go or Python yet.

### `internal/pb/` (The Go Code)
This folder contains the **generated Go code**. You never write files here manually; the compiler (`protoc`) writes them for you.
*   **`search.pb.go`**: Contains the Go structs.
    *   It translates `message SearchRequest { ... }` into `type SearchRequest struct { ... }`.
    *   It handles serializing that struct into binary bytes to send over the wire.
*   **`search_grpc.pb.go`**: Contains the networking logic.
    *   **Client Interface**: Defines a Go interface `SemanticEmbeddingServiceClient` that our main app can call like a normal function.
    *   **Server Interface**: Defines an interface that a Go server *would* implement (we don't use this, because our server is Python).

### `embedding/*_pb2*.py` (The Python Code)
These are the Python equivalents generated by the compiler.
*   **`search_pb2.py`**: Contains the Python classes for messages (e.g., `SearchRequest`).
    *   Why `_pb2`? It stands for "Protocol Buffers Version 2" (even though we use proto3 syntax, the Python library convention stuck).
*   **`search_pb2_grpc.py`**: Contains the networking logic.
    *   **`SemanticEmbeddingServiceServicer`**: A parent class that we must inherit from to implement our actual server logic.
    *   **`SemanticEmbeddingServiceStub`**: The client class (we don't use this, because our client is Go).

## 3. How It All Connects

Here is the lifecycle of a request:

1.  **Define**: We write `rpc Search(SearchRequest) returns (SearchResponse)` in `proto/search.proto`.
2.  **Generate**: We run `make` commands to run the `protoc` compiler. It reads the `.proto` file and spits out the Go and Python code described above.
3.  **Implement (Python)**:
    *   We create `embedding/semantic_search.py`.
    *   We import `search_pb2_grpc` and inherit from the generated `Servicer` class.
    *   We override the `Search` method to add our actual logic (loading PyTorch models, calculating dot products).
4.  **Call (Go)**:
    *   We write code in `main.go`.
    *   We import `internal/pb`.
    *   We create a client: `client := pb.NewSemanticEmbeddingServiceClient(conn)`.
    *   We call `client.Search(...)`.
5.  **Runtime**:
    *   Go calls `Search`. The generated code converts the arguments into binary Protobuf format.
    *   It sends these bytes over the network (localhost:50051) to the Python process.
    *   Python's generated code receives bytes, unpacks them into a Python object, and calls our `Search` method.
    *   The result goes back the same way.

## 4. Setup for Development

If you edit the `.proto` file, you must **regenerate** the code.

### Prerequisites (macOS)
```bash
brew install protobuf
go install google.golang.org/protobuf/cmd/protoc-gen-go@latest
go install google.golang.org/grpc/cmd/protoc-gen-go-grpc@latest
export PATH=$PATH:$(go env GOPATH)/bin
```

### Commands

#### Generate Go Code
Writes to `internal/pb/`:
```bash
protoc --go_out=. --go-grpc_out=. proto/search.proto
```

#### Generate Python Code
Writes to `embedding/`:
```bash
cd embedding && uv run python -m grpc_tools.protoc -I../proto --python_out=. --grpc_python_out=. ../proto/search.proto
```
